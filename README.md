#### [GamifyLearn](https://github.com/harshitha7104/GamifyLearn--Gamification-Impact-Learner-Engagement-Analysis) · [Live dashboard](https://gamifylearn--gamification-impact-learner-engagement-analysis-s.streamlit.app/)

A 5,000-learner simulated study measuring how streaks, XP/leaderboards, and personalised rewards affect 30-day course completion, with ROI scenario modeling.

### Software & systems

#### [CodeAtlas](https://github.com/harshitha7104/codeatlas-static-analyzer) · [Live demo](https://codeatlas-static-analyzer.vercel.app)

A compiler-inspired static analyzer for Python that builds ASTs, symbol tables, and control-flow, data-flow, call, and dependency graphs to power bug detection, metrics, and change-impact analysis.

#### [Vector Database with HNSW](https://github.com/harshitha7104/modern-vector-database)

A from-scratch C++ implementation of Hierarchical Navigable Small World graphs for approximate nearest-neighbor search, with a storage layer and binary persistence format.

A dependency conflict resolver with a custom semver engine, live npm registry data, a backtracking constraint solver, and an AI explanation layer.
